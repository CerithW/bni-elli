# BNI Elli tools

Small, single-file web pages for the chapter. No logins, no servers; each page keeps its data in the browser of the device it is opened on.

| Page | Address | What it is for |
|---|---|---|
| Action Plan | https://cerithw.github.io/bni-elli/ | Monthly member action plan with the points and Traffic Light status |
| Passport to Success | https://cerithw.github.io/bni-elli/passport/ | New member mentoring: the member's passport, mentor crib sheets for all ten sessions, the Mentor Coordinator's tracker, and the reference rules |

## Passport to Success

Built from the BNI South Wales *Passport to Success 2026-27* pack (ten mentor crib sheets, ten slide decks, the mentor tracking sheet, the effectiveness review checklist and the General Policies), de-duplicated onto one page.

- **My Passport** – for the new member. The 13 items in the tracking sheet's order (Sessions 1–4, Launch Pad, 5–10, Regional sign-off, MSP), each with who to book it with, what it covers, what to do before and after, and a stamp when signed off. Shows week number, the 84-day target date and pace.
- **Mentor crib sheets** – one screen per session. A direct link to a session is `…/passport/#mentor-7` (change the number).
- **Coordinator tracker** – replaces the spreadsheet. Data stays on the Coordinator's own device; use **Export** before changing phone or handing over, and **Copy weekly summary** for Announcements.
- **Reference** – the rules that recur across the sessions.

## Editing

Each page is one `index.html` with its styles and script inside. Edit the file, commit to `main`, and GitHub Pages publishes it within a minute or two.
